# OIBSIP Python Programming Internship

## About

This repository contains the projects completed as part of the **Python Programming Internship** at **Oasis Infobyte**.

The projects demonstrate practical Python programming concepts, GUI development, database handling, API integration, and application development.

---

## Projects

### Task 2 — BMI Calculator

A BMI Calculator application that calculates Body Mass Index based on the user's weight and height.

#### Features

- Calculate BMI
- Display BMI category
- User name support
- Save BMI records
- SQLite database
- BMI history
- BMI trend graph
- Input validation
- Error handling

#### Technologies

- Python
- Tkinter
- SQLite
- Matplotlib

---

### Task 3 — Random Password Generator

A password generator application that creates strong and random passwords.

#### Features

- Generate random passwords
- Custom password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters
- Password strength indicator
- Copy password
- Password history

#### Technologies

- Python
- Tkinter
- Secrets
- String

---

### Task 4 — Basic Weather App

A weather application that provides weather information for a selected location.

#### Features

- Search weather by city
- Current temperature
- Weather condition
- Humidity
- Wind information
- Weather details
- API-based weather data
- User-friendly interface

#### Technologies

- Python
- Tkinter
- OpenWeatherMap API
- Requests
