# Task 2 - BMI Calculator

## About

This project is an advanced BMI Calculator developed using Python.

The application calculates a user's Body Mass Index (BMI) using weight and height. It also stores BMI records for different users and provides a BMI trend graph.

## Features

- Calculate BMI
- User name support
- Weight input in kilograms
- Height input in meters
- BMI category classification
- Colour-coded BMI result
- Input validation
- Error handling
- Multiple-user support
- SQLite database
- BMI history
- Search BMI records
- Update records
- Delete records
- BMI trend graph
- Dashboard
- CSV export

## BMI Categories

| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 - 24.9 | Normal |
| 25 - 29.9 | Overweight |
| 30 and above | Obese |

## Technologies Used

- Python
- Tkinter
- SQLite
- Matplotlib
- CSV
