# Task 4 – Advanced Weather App

## About the Project

This project is an advanced Weather Application developed using Python and Tkinter.

The application allows users to search for weather information by entering a city name. It provides a clean graphical interface with weather details, search history, temperature information, and additional weather insights.

## Features

- 🌤️ City-based weather search
- 🌡️ Current temperature display
- 💧 Humidity information
- 💨 Wind speed information
- 🌧️ Weather condition display
- 📊 Weather information dashboard
- 🔍 Search by city name
- 🕒 Search history
- 🗑️ Clear search history
- 📋 Copy weather information
- 🔄 Refresh weather information
- ⚠️ Error handling for invalid city names
- 📱 User-friendly Tkinter GUI
- 🎨 Modern and organized interface
- 🌍 Support for different cities
- ⌨️ Simple keyboard-friendly controls

## Technologies Used

- Python
- Tkinter
- JSON
- URL/API handling
- Standard Python Libraries
